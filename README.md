# 🎓 Pós-Graduação em Engenharia de Software com IA Aplicada (UNIPDS)

Repositório pessoal com anotações, resumos, explicações e projetos práticos desenvolvidos ao longo da pós-graduação em **Engenharia de Software com IA Aplicada** (UNIPDS).

---

## 📂 Estrutura do Repositório

```bash
.
├── modulo01-fundamentos-de-ia-e-llms-para-programadores/  # ML/DL, embeddings, RAG, observabilidade
├── modulo02-integracao-apis-llms/                         # Gateways, guardrails, roteamento, RAG com grafos
├── modulo03-mcp-na-pratica/                                # Model Context Protocol: servidores, skills, segurança
├── modulo04-agentes-autonomos/                             # Loops de agente, memória, evals, arquiteturas cognitivas
├── modulo05-ferramentas-de-IA-para-UI-UX/                  # Ferramentas de IA para UX & UI
├── modulo06-aiops-engenharia-agentica/                     # AIOps: IaC, Kubernetes, observabilidade, copilots
├── modulo07-ferramentas-de-ia-para-gestao-de-projetos/     # Gestão de projetos assistida por IA (caso RouteWise)
├── modulo08-arquitetura-de-sistemas-com-ia/                # Arquitetura de sistemas AI-first, single/multi-agent
├── lives/                                                  # Anotações das lives da pós, organizadas por data
└── embaixadores/                                           # Material do programa de embaixadores
```

Cada módulo tem sua própria pasta com os projetos práticos das aulas (quando aplicável, com versão em Go e em Java) e, em alguns casos, um `README.md` próprio detalhando a estrutura interna.

## 📄 Resumos e Explicações por Módulo

Para cada tema estudado, a raiz do repositório mantém um par de documentos `.docx` (gerados a partir do PDF da aula) mais o PDF original:

| Tema | Resumo | Explicação Detalhada |
|------|--------|------------------------|
| Fundamentos de IA e LLMs para Programadores | ✅ | ✅ |
| APIs de IA Generativa e Prompt Engineering | ✅ | ✅ |
| Model Context Protocol (MCP) | ✅ | ✅ |
| Criação de Agentes Autônomos | ✅ | ✅ |
| Ferramentas de IA para UX & UI | ✅ | ✅ |
| Ferramentas de IA para DevOps | ✅ | ✅ |
| Ferramentas de IA para Gestão de Projetos | ✅ | ✅ |
| Arquitetura de Sistemas com IA | ⏳ | ⏳ |

- **Resumo** — síntese objetiva dos pontos-chave da aula.
- **Explicação Detalhada** — aprofundamento didático de cada conceito, com exemplos.

## ▶️ Como navegar

1. Comece pelo PDF/`.docx` do módulo na raiz para revisar o conteúdo teórico.
2. Entre na pasta `moduloXX-*` correspondente para ver os projetos práticos das aulas.
3. Módulos com `README.md` próprio (05, 06, 07) trazem instruções específicas de uso dos artefatos daquela disciplina.
